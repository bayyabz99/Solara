# SOLARA görsel yuvaları

Dosya yoksa sitede çizilmiş yer tutucu görünür. Aşağıdaki adlarla dosyayı koymanız yeterli
(`.webp` önce denenir, yoksa `.png`). Adları değiştirmek isterseniz `js/config.js` içinden değiştirin.

| Klasör / dosya | Ne | Önerilen boyut / format |
|---|---|---|
| `logo.svg` (veya `logo.png`) | Marka logosu (menü ve yükleme perdesi) | SVG veya şeffaf PNG, ~400x120 |
| `hero/hero-bottle.webp` | Ana sayfa şişe/kutu | Şeffaf, dikey, ~1200x1800 |
| `hero/hero-bg.webp` (veya `.jpg`) | Ana sayfa arka plan dokusu (isteğe bağlı) | 1920x1080 |
| `products/mango.webp` | Mango ürün görseli | Şeffaf arka plan, dikey, ~1200x1800 |
| `products/nar.webp` | Nar | aynı |
| `products/limon-nane.webp` | Limon & Nane | aynı |
| `products/yaban-mersini.webp` | Yaban Mersini | aynı |
| `products/seftali.webp` | Şeftali | aynı |
| `ingredients/<meyve>-1..3.png` | Ürün çevresinde süzülen malzemeler (dilim, yaprak, tane…) | Şeffaf PNG, ~500x500 |
| `stores/store-1..4.svg` | "Nerede bulunur" mağaza logoları | SVG, beyaz veya tek renk |

Malzeme adları: `mango-`, `nar-`, `limon-`, `mersin-`, `seftali-` + `1`, `2`, `3`.

Not: Ürün görselleri şeffaf arka planlı olmalı; sahnenin rengi arkadan görünür.
